# Assets Directory

本ディレクトリ（`assets/`）に、外部で作成されたアプリアイコンや画像アセットを配置してください。

## 推奨ファイル
- `app.ico`: Windows アプリケーション用アイコン（マルチサイズ: 16x16, 24x24, 32x32, 48x48, 64x64, 128x128, 256x256 推奨）
- `app.png`: 高解像度元画像（512x512 または 1024x1024）

## 参照先
- `src/VolumeProfileManager.TrayApp/VolumeProfileManager.TrayApp.csproj`
- `installer/VolumeProfileManager.iss`
